`natural-earth-110m.json` contains the outer polygon rings from Natural Earth's
1:110m Admin 0 countries GeoJSON, rounded to two decimal places and stripped of
metadata for a compact client-side globe texture (153 KB). Natural Earth data is
public domain: https://www.naturalearthdata.com/about/terms-of-use/

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
